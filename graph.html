Type a formula, see the curve. Use y = sin(x) for an explicit plot, (cos(t), sin(t)) for a parametric one. Any name = number row becomes a slider. Press Enter to add a row.

Syntax
  • y = f(x) — plot y as a function of x
  • (fx(t), fy(t)) — parametric curve in t
  • k = 3 — defines a slider you can drag
  • Allowed: + − × ÷ ^, sin cos tan exp ln sqrt abs, pi e g tau
  • Drag canvas to pan, scroll to zoom
