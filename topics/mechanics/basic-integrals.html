Basic Integrals (power rule, trig)

Integration as the reverse of differentiation: antiderivatives, the basic table (powers, eˣ, sin, cos), definite integrals and the fundamental theorem of calculus.

In short

Integrating is differentiating backwards. A derivative takes a function and tells you how fast it changes. An integral goes the other way: you know how fast something changes, and you want the thing itself. A function $F$ with $F' = f$ is called an antiderivative of $f$ [1]; [2].

Don't forget $+C$. Adding any constant doesn't change the slope, so there are many antiderivatives: $\int f\,dx = F(x) + C$ [1]; [2]. In mechanics $C$ is fixed by where you started, such as $x(0)$ or $v(0)$ [1].

The basic recipes (each one is a derivative rule read backwards) [1]; [2]:

  • powers: raise the power by one and divide by the new power, $\int x^n dx = \frac{x^{n+1}}{n+1} + C$ (not for $n = -1$);
  • for $n = -1$: $\int \frac{dx}{x} = \ln|x| + C$;
  • $\int e^x dx = e^x + C$, $\int \cos x\,dx = \sin x + C$, $\int \sin x\,dx = -\cos x + C$;
  • with $kx$ inside, divide by $k$: $\int e^{kx}dx = \frac1k e^{kx} + C$.

The definite integral is an area. Cut the space under a curve into thin strips and add up their areas. As the strips get infinitely thin you get $\int_a^b f(x)\,dx$ [3]. Area below the $x$-axis counts as negative [1]; [4].

The big shortcut (the fundamental theorem): you don't have to add strips. Just take any antiderivative and subtract, $\int_a^b f\,dx = F(b) - F(a)$ [4]. For motion: adding up velocity over time gives how far you moved, $\int v\,dt = \Delta x$. Careful: going forward and then back gives a net movement of zero, even though your legs walked a long way [4].

Theory

Antiderivatives

An antiderivative of $f(x)$ is any function $F(x)$ whose derivative is $f(x)$: $F'(x) = f(x)$ [1, §Antiderivatives]. For example, $x^3$ is an antiderivative of $3x^2$.

Antiderivatives are never unique, because adding a constant does not change the derivative: $x^3 + 5$ also has derivative $3x^2$. The converse is also true. If $F' = f$ and $G' = f$, then $(G-F)' = 0$, so $G - F$ is a constant [2]. Every antiderivative of $f$ is therefore $F(x) + C$ for some constant $C$.

The indefinite integral is the notation for this whole family. Here $F$ is any antiderivative of $f$ [1, §Indefinite Integrals]:

$$\int f(x)\,dx = F(x) + C.$$

The basic table

Each entry comes from reading a derivative formula backwards, and each can be checked by differentiating the right-hand side [1]; [2]:

$$\begin{gathered} \int x^n\,dx = \frac{x^{n+1}}{n+1} + C \quad (n \ne -1), \\ \int \frac{dx}{x} = \ln|x| + C, \qquad \int e^x\,dx = e^x + C, \\ \int \cos x\,dx = \sin x + C, \\ \int \sin x\,dx = -\cos x + C. \end{gathered}$$

The power rule fails for $n = -1$ because it would divide by zero; that case is covered by $\ln|x|$. The absolute value makes the formula work for negative $x$ too: for $x < 0$, $\frac{d}{dx}\ln(-x) = \frac{1}{-x}\cdot(-1) = \frac{1}{x}$ [2].

Integrals of sums and constant multiples split term by term, just like derivatives: $\int(af + bg)\,dx = a\int f\,dx + b\int g\,dx$.

Linear inner functions: guess and check

When the argument is $kx$ instead of $x$, guess the obvious answer and correct it with the chain rule [2]. For example, $\frac{d}{dx}e^{kx} = k\,e^{kx}$, so the guess $e^{kx}$ is too big by a factor $k$:

$$\begin{gathered} \int e^{kx}\,dx = \frac{1}{k}e^{kx} + C, \\ \int \sin(kx)\,dx = -\frac{1}{k}\cos(kx) + C, \\ \int \cos(kx)\,dx = \frac{1}{k}\sin(kx) + C. \end{gathered}$$

The same idea works whenever the integrand contains the derivative of an inner function, for example $\int x\,e^{-x^2}dx = -\frac12 e^{-x^2} + C$ [2].

The definite integral

To find the area under $y = f(x)$ between $x = a$ and $x = b$, divide $[a,b]$ into $n$ strips of width $\Delta x = (b-a)/n$, pick a point $c_i$ in each strip, and add up the rectangles $f(c_i)\,\Delta x$. Letting the strips become infinitely thin defines the definite integral [3]:

$$\int_a^b f(x)\,dx = \lim_{n\to\infty}\sum_{i=1}^{n} f(c_i)\,\Delta x.$$

Unlike an indefinite integral, this is a number. It is a signed area: parts of the graph below the $x$-axis count as negative [1, §Definite Integrals]; [4].

The fundamental theorem of calculus

Computing Riemann sums directly is hard. The fundamental theorem replaces it with an antiderivative: if $f$ is continuous and $F' = f$, then [4]; [1]

$$\int_a^b f(x)\,dx = F(b) - F(a) = \Big[F(x)\Big]_a^b.$$

The constant $C$ cancels in the difference, so any antiderivative will do.

In mechanics the most important case is velocity. Since $v = \dot x$, the theorem says $\int_{t_1}^{t_2} v\,dt = x(t_2) - x(t_1)$: integrating velocity over time gives the displacement [4]. In the same way, integrating acceleration gives the change in velocity.

Two useful properties: integrals over adjacent intervals add, $\int_a^b f\,dx + \int_b^c f\,dx = \int_a^c f\,dx$, and swapping the limits changes the sign, $\int_b^a f\,dx = -\int_a^b f\,dx$ [4].

Note

$\int_a^b v\,dt$ is the net displacement, not the distance travelled. If the particle turns around, the backward part has $v < 0$ and cancels part of the forward motion. For a round trip the integral is zero, even though the odometer shows a positive distance [4].

Warning

Don't forget the constant $C$ in an indefinite integral. In mechanics it is not a detail: it is fixed by the initial condition, such as $v(0)$ or $x(0)$. Dropping it gives the wrong motion (see Example 3) [1, Worked Example 7].

Visualization

The area under $f(x) = x^2$ from $0$ to $b$ is filled with $n$ rectangles whose height is the value of $f$ at each strip's right edge. Every 1.2 s the number of strips doubles ($n = 1, 2, 4, \dots, 64$). The rectangle sum, shown at the top, gets closer and closer to the exact area $b^3/3$, which is what the definite integral $\int_0^b x^2\,dx$ gives by the fundamental theorem. Move $b$ to change the interval.

Key formulas

Worked examples

Example

Evaluate $\displaystyle\int(3x^2 - 4x + 5)\,dx$, $\displaystyle\int\left(\frac{2}{x} + e^x\right)dx$ and $\displaystyle\int\sin(2x)\,dx$. (From [1], Worked Example 7(a).)

  1. Term by term with the power rule:

    $$\begin{aligned} &\int(3x^2 - 4x + 5)\,dx \\ &\quad= x^3 - 2x^2 + 5x + C. \end{aligned}$$

  2. Use $\int dx/x = \ln|x|$ and $\int e^x dx = e^x$:

    $$\int\left(\frac{2}{x} + e^x\right)dx = 2\ln|x| + e^x + C.$$

  3. Linear inner function with $k = 2$:

    $$\int\sin(2x)\,dx = -\frac12\cos(2x) + C.$$

Check

Differentiate the last answer: $\frac{d}{dx}\left(-\frac12\cos 2x\right) = -\frac12\cdot(-\sin 2x)\cdot 2 = \sin 2x$. ✓

Example

Evaluate $\displaystyle\int_0^3(2x+1)\,dx$, $\displaystyle\int_0^\pi\sin x\,dx$ and $\displaystyle\int_{-1}^{1}x^3\,dx$. (From [1], Worked Example 7(b).)

  1. $\displaystyle\int_0^3(2x+1)\,dx = \Big[x^2 + x\Big]_0^3 = 12.$

  2. $\displaystyle\int_0^\pi\sin x\,dx = \Big[-\cos x\Big]_0^\pi = 1 + 1 = 2.$

  3. $\displaystyle\int_{-1}^{1}x^3\,dx = \Big[\tfrac{x^4}{4}\Big]_{-1}^{1} = \tfrac14 - \tfrac14 = 0.$ The negative area on $[-1, 0]$ exactly cancels the positive area on $[0, 1]$.

Check

The first integral is the area of a trapezoid with parallel sides $f(0) = 1$ and $f(3) = 7$ and width $3$: $\frac{1+7}{2}\cdot 3 = 12$. ✓

Example

A particle has acceleration $a(t) = 6t\ \text{m/s}^2$, with $v(0) = 2\ \text{m/s}$ and $x(0) = 0$. Find $v(t)$, $x(t)$ and the displacement during the first $2\ \text{s}$. (From [1], Worked Example 7(c).)

  1. Integrate the acceleration: $v(t) = \int 6t\,dt = 3t^2 + C_1$. The initial condition $v(0) = 2$ gives $C_1 = 2$, so $v(t) = 3t^2 + 2$.

  2. Integrate again: $x(t) = \int(3t^2+2)\,dt = t^3 + 2t + C_2$. From $x(0) = 0$, $C_2 = 0$, so $x(t) = t^3 + 2t$.

  3. Displacement by the fundamental theorem:

    $$\begin{aligned} \Delta x &= \int_0^2(3t^2+2)\,dt \\ &= \Big[t^3 + 2t\Big]_0^2 = 12\ \text{m}. \end{aligned}$$

Check

$x(2) - x(0) = (8 + 4) - 0 = 12\ \text{m}$, the same answer. Differentiating $x(t)$ twice gives back $a = 6t$. ✓

Example

Find $\displaystyle\int e^{6x}\,dx$ and $\displaystyle\int x\,e^{-x^2}\,dx$ by guessing and checking. (From [2], Examples 3 and 4.)

  1. Guess $e^{6x}$. Its derivative is $6e^{6x}$, six times too big, so divide by 6:

    $$\int e^{6x}\,dx = \frac16 e^{6x} + C.$$

  2. Guess $e^{-x^2}$. Its derivative is $-2x\,e^{-x^2}$, which is $-2$ times the integrand, so divide by $-2$:

    $$\int x\,e^{-x^2}\,dx = -\frac12 e^{-x^2} + C.$$

Check

$\frac{d}{dx}\left(-\frac12 e^{-x^2}\right) = -\frac12\cdot(-2x)\,e^{-x^2} = x\,e^{-x^2}$. ✓
