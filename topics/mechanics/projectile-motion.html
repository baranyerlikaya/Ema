Projectile Motion

A body thrown near the Earth's surface, with air resistance neglected: uniform motion sideways plus uniformly accelerated motion up and down, giving a parabola.

In short

Throw a ball and, if we ignore the air, only one thing pulls on it: gravity, straight down. So the ball's motion splits into two easy pieces [1]; [2]:

  • Sideways: nothing pushes it, so it keeps the same sideways speed the whole time: $x = v_0\cos\theta\;t$.
  • Up and down: gravity slows it on the way up, stops it at the top, and speeds it up on the way down: $y = v_0\sin\theta\;t - \tfrac12gt^2$.

Here $v_0$ is how fast you throw and $\theta$ is the angle above the ground. Splitting $v_0$ into $v_0\cos\theta$ (sideways) and $v_0\sin\theta$ (up) gives the starting speeds of the two pieces [1].

At the very top the ball isn't moving up or down at all for a moment ($v_y = 0$). It is still moving sideways. That happens at $t = v_0\sin\theta/g$, at height $v_0^2\sin^2\theta/2g$ [1].

Coming down takes as long as going up (on flat ground), so the whole flight is $2v_0\sin\theta/g$. In that time it travels sideways a distance (the range) $v_0^2\sin2\theta/g$. The longest throw is at $45^\circ$, and angles like $30^\circ$ and $60^\circ$ land at the same spot [1].

The shape of the path is a parabola, like an upside-down U [1]; [2]. Real air makes the path shorter, so these formulas are the "no-air" version [2].

Theory

The model

Take the $x$-axis horizontal (in the direction of the throw) and the $y$-axis vertically up. If we neglect everything except gravity, the only force is $\mathbf F = -mg\,\hat\jmath$, so by Newton's second law [2, §5.2]; [1, Worked Example “Projectile Motion”]:

$$a_x = 0, \qquad a_y = -g.$$

The acceleration is the same for every mass, and it is constant. Horizontally nothing changes the velocity; vertically the body falls freely [2, §5.2].

Initial conditions

A body launched with speed $v_0$ at angle $\theta$ above the horizontal has initial velocity components [1]; [2, §5.2]

$$v_{0x} = v_0\cos\theta, \qquad v_{0y} = v_0\sin\theta.$$

Position and velocity

Integrate each direction separately (constant acceleration in each) [2, §5.2]; [1]. With the launch point at $(x_0, y_0)$:

$$\begin{aligned} x(t) &= x_0 + v_{0x}t, & v_x(t) &= v_{0x}, \\ y(t) &= y_0 + v_{0y}t - \tfrac12gt^2, & v_y(t) &= v_{0y} - gt. \end{aligned}$$

The horizontal velocity never changes; the vertical velocity decreases by $g$ every second, passes through zero at the top, and then becomes negative [2, Example 5.1].

Time of flight, maximum height, range

For a launch from the ground ($x_0 = y_0 = 0$) back to the ground [1, Worked Example “Projectile Motion”]:

  • the top is reached when $v_y = 0$, at $t_{\text{up}} = v_0\sin\theta/g$;
  • the flight lasts twice as long, $t_{\text{flight}} = 2v_0\sin\theta/g$;
  • the maximum height is $y_{\max} = \dfrac{v_0^2\sin^2\theta}{2g}$;
  • the range is $x_{\max} = v_{0x}t_{\text{flight}} = \dfrac{v_0^2\sin2\theta}{g}$.

The trajectory is a parabola

Eliminate $t$ using $t = x/(v_0\cos\theta)$ (launch from the origin) [1]; [2, §5.2.1]:

$$y(x) = x\tan\theta - \frac{g\,x^2}{2v_0^2\cos^2\theta}.$$

This is a quadratic in $x$, so the path is a parabola that opens downward [1].

Note

Real projectiles feel air resistance, which can shorten the path a lot. In MIT's example (a ball at $30\ \text{m/s}$, $21^\circ$, with quadratic drag) the actual range is only about $72\%$ of the parabolic one [2, §5.2]. The formulas here are for the idealized, drag-free case.

Warning

The range formula $v_0^2\sin2\theta/g$ and the doubled time of flight only hold when the projectile lands at the same height it was launched from. If it starts at a height $d$, solve $y(t) = 0$ directly [2, Example 5.1].

Key formulas

Worked examples

Example

A particle is launched from the ground with speed $v_0$ at angle $\theta$. Find the time of flight, the maximum height, the range and the trajectory $y(x)$. (From [1], Worked Example “Projectile Motion”.)

  1. Vertical: $v_y = v_0\sin\theta - gt$ is zero at $t_{\text{up}} = v_0\sin\theta/g$. By symmetry $t_{\text{flight}} = 2t_{\text{up}} = 2v_0\sin\theta/g$.

  2. Height at $t_{\text{up}}$: $y_{\max} = v_0\sin\theta\,t_{\text{up}} - \tfrac12gt_{\text{up}}^2 = \dfrac{v_0^2\sin^2\theta}{2g}$.

  3. Horizontal: $x_{\max} = v_0\cos\theta\cdot\dfrac{2v_0\sin\theta}{g} = \dfrac{v_0^2\sin2\theta}{g}$, using $2\sin\theta\cos\theta = \sin2\theta$.

  4. Substitute $t = x/(v_0\cos\theta)$ into $y(t)$: $y = x\tan\theta - \dfrac{gx^2}{2v_0^2\cos^2\theta}$.

Check

Put $x = x_{\max}$ into $y(x)$: $\tan\theta\cdot\frac{2v_0^2\sin\theta\cos\theta}{g} - \frac{g}{2v_0^2\cos^2\theta}\cdot\frac{4v_0^4\sin^2\theta\cos^2\theta}{g^2} = \frac{2v_0^2\sin^2\theta}{g} - \frac{2v_0^2\sin^2\theta}{g} = 0$. The path lands at the range. ✓

Example

A stone is thrown at $45^\circ$ with $v_0 = 20\ \text{m/s}$ from a height $d = 2\ \text{m}$. When does it reach its highest point, and how high is it? Use $g = 9.8\ \text{m/s}^2$. (From [2], Example 5.1.)

  1. At the top $v_y = 0$: $t_1 = \dfrac{v_0\sin45^\circ}{g} = \dfrac{20 \times 0.707}{9.8} \approx 1.44\ \text{s}$.

  2. Height: $y_{\max} = d + \dfrac{v_0^2\sin^2 45^\circ}{2g} = 2 + \dfrac{400 \times 0.5}{19.6} \approx 12.2\ \text{m}$.

Check

The launch height only adds $d$ to the maximum height; the time to the top doesn't depend on $d$ at all, since it only depends on $v_y$. ✓

Example

Using the range formula, which launch angle gives the longest range on level ground? Show that $\theta$ and $90^\circ - \theta$ give the same range. (Adapted from [1], Worked Example “Projectile Motion”, part (c).)

  1. $x_{\max} = v_0^2\sin2\theta/g$ is largest when $\sin2\theta = 1$, i.e. $2\theta = 90^\circ$: $\theta = 45^\circ$, with $x_{\max} = v_0^2/g$.

  2. For $90^\circ - \theta$: $\sin(2(90^\circ - \theta)) = \sin(180^\circ - 2\theta) = \sin2\theta$. Same range.

Check

The steeper throw goes higher and stays in the air longer ($t_{\text{flight}} \propto \sin\theta$) but moves more slowly sideways ($v_{0x} \propto \cos\theta$); the two effects exactly compensate. ✓
