Derivatives of sin, cos, eˣ, ln

Derivatives of the functions that appear everywhere in mechanics, sin, cos, eˣ and ln x, and how to combine them with the chain rule.

In short

[Basic explanation]

Theory

Two trigonometric limits

Everything about the derivatives of sine and cosine rests on two limits, with $\theta$ measured in radians [2]:

$$\lim_{\theta\to 0}\frac{\sin\theta}{\theta} = 1, \qquad \lim_{\theta\to 0}\frac{1-\cos\theta}{\theta} = 0.$$

Picture a unit circle and a small angle $\theta$. The arc has length $\theta$ and the vertical side of the triangle under it has length $\sin\theta$. As $\theta$ shrinks, the arc and that side become almost the same, so their ratio tends to $1$. The gap $1-\cos\theta$ between the triangle and the circle shrinks much faster than $\theta$, so the second ratio tends to $0$ [2].

Derivatives of sin x and cos x

Start from the definition and use the addition formula $\sin(x+\Delta x) = \sin x\cos\Delta x + \cos x\sin\Delta x$ [3]:

$$\begin{aligned} &\frac{\sin(x+\Delta x)-\sin x}{\Delta x} \\ &\quad= \sin x\,\frac{\cos\Delta x - 1}{\Delta x} + \cos x\,\frac{\sin\Delta x}{\Delta x}. \end{aligned}$$

As $\Delta x \to 0$ the first fraction goes to $0$ and the second to $1$, so

$$\frac{d}{dx}\sin x = \cos x.$$

The same steps with $\cos(x+\Delta x) = \cos x\cos\Delta x - \sin x\sin\Delta x$ give $\frac{d}{dx}\cos x = -\sin x$ [3]. Applying the quotient rule to $\tan x = \sin x/\cos x$ then gives $\frac{d}{dx}\tan x = \sec^2 x = 1/\cos^2 x$ [1, §Derivatives of Common Functions].

The exponential function eˣ

For any base $a > 1$, factor $a^x$ out of the difference quotient [5]:

$$\frac{a^{x+\Delta x}-a^x}{\Delta x} = a^x\,\frac{a^{\Delta x}-1}{\Delta x}.$$

The remaining fraction does not depend on $x$. Its limit is just the slope of the graph of $a^x$ at $x = 0$; call it $M(a)$. So $\frac{d}{dx}a^x = M(a)\,a^x$: the derivative of an exponential is proportional to the exponential itself.

The slope $M(a)$ grows with $a$. It is less than $1$ for $a = 2$ and more than $1$ for $a = 4$, so there is one base in between with slope exactly $1$. That base is the number $e \approx 2.718$, and for it [5]

$$\frac{d}{dx}e^x = e^x.$$

The natural logarithm ln x

The natural logarithm undoes the exponential: $w = \ln x$ means $e^w = x$, for $x > 0$. Differentiate both sides of $e^w = x$ with respect to $x$, using the chain rule on the left [5]:

$$e^w\,\frac{dw}{dx} = 1 \quad\Longrightarrow\quad \frac{dw}{dx} = \frac{1}{e^w} = \frac{1}{x}.$$

So $\frac{d}{dx}\ln x = \frac{1}{x}$. This also fixes the slope $M(a)$ from above. Writing $a^x = e^{x\ln a}$ and using the chain rule gives $\frac{d}{dx}a^x = (\ln a)\,a^x$, so $M(a) = \ln a$ [5].

Combining with the chain rule

In mechanics these functions almost always appear with an inner function of time, such as $\sin(\omega t + \varphi)$ or $e^{-bt}$. The chain rule turns the inner derivative into a constant factor [1, Worked Example 5]; [4]:

$$\begin{gathered} \frac{d}{dt}e^{kt} = k\,e^{kt}, \\ \frac{d}{dt}\sin(\omega t+\varphi) = \omega\cos(\omega t+\varphi), \\ \frac{d}{dt}\cos(\omega t+\varphi) = -\omega\sin(\omega t+\varphi). \end{gathered}$$

Differentiating $\sin$ or $\cos$ twice brings back the same function times $-\omega^2$. That is exactly the equation of simple harmonic motion, $\ddot x = -\omega^2 x$ (see Example 2) [1, Worked Example 5(c)].

Note

$e^x$ is positive for every $x$, even negative $x$. Since $\ln x$ is the inverse of $e^x$, it is defined only for $x > 0$ [5].

Warning

The formulas $\frac{d}{dx}\sin x = \cos x$ and $\frac{d}{dx}\cos x = -\sin x$ are only true when $x$ is in radians. In degrees an extra factor $\pi/180$ appears, because the limit $\sin\theta/\theta \to 1$ uses radians [2].

Worked examples

Example

Differentiate $g(x) = x^2\sin x$ and $h(x) = \sin(3x^2+1)$. (From [1], Worked Example 5(a).)

  1. $g$ is a product, so use the product rule with $(x^2)' = 2x$ and $(\sin x)' = \cos x$:

    $$g'(x) = 2x\sin x + x^2\cos x.$$

  2. $h$ is a composite: outer $\sin u$, inner $u = 3x^2+1$ with $u' = 6x$. By the chain rule,

    $$h'(x) = 6x\cos(3x^2+1).$$

Example

For simple harmonic motion $x(t) = A\sin(\omega t + \varphi)$, show that the acceleration is $a = -\omega^2 x$. (From [1], Worked Example 5(c).)

  1. First derivative, with the chain rule (inner derivative $\omega$):

    $$v = \dot x = A\omega\cos(\omega t+\varphi).$$

  2. Second derivative:

    $$a = \dot v = -A\omega^2\sin(\omega t+\varphi) = -\omega^2 x.$$

Check

Units: $\omega^2 x$ has units $\text{s}^{-2}\cdot\text{m} = \text{m/s}^2$, as an acceleration should. The minus sign means the acceleration always points back toward $x = 0$, which is what a spring force does [1].

Example

For damped motion $x(t) = A e^{-bt}\cos\omega t$, find $\dot x$. (From [1], Worked Example 5(d).)

  1. This is a product of $e^{-bt}$ and $\cos\omega t$. Their derivatives are $-b\,e^{-bt}$ and $-\omega\sin\omega t$ (chain rule).

  2. Product rule, with the common factor $e^{-bt}$ already pulled out:

    $$\dot x = A\,e^{-bt}\left[-b\cos\omega t - \omega\sin\omega t\right].$$

  3. Factor out the common terms:

    $$\dot x = -A\,e^{-bt}\left(b\cos\omega t + \omega\sin\omega t\right).$$

Check

Setting $b = 0$ (no damping) gives $\dot x = -A\omega\sin\omega t$, the derivative of $A\cos\omega t$, as it should.

Example

Differentiate $f(x) = x^x$ for $x > 0$. (From [5], Example 1.)

  1. The exponent is not constant, so neither the power rule nor the $a^x$ rule applies. Take the logarithm first: $\ln f = x\ln x$.

  2. Differentiate both sides. On the left the chain rule gives $f'/f$; on the right use the product rule:

    $$\frac{f'}{f} = 1\cdot\ln x + x\cdot\frac{1}{x} = \ln x + 1.$$

  3. Multiply by $f$:

    $$f'(x) = x^x(\ln x + 1).$$

Check

At $x = 1$: $f'(1) = 1\cdot(0+1) = 1$. The slope is positive there, and indeed $x^x$ is increasing near $x = 1$ ($0.9^{0.9} \approx 0.91 < 1 < 1.1^{1.1} \approx 1.11$).
