Inclined Plane, Tension

Blocks on inclined planes with and without friction, and tension in strings that connect bodies: how to draw free-body diagrams, pick axes along the surface and apply Newton's second law.

In short

A block on a tilted ramp. Three things can push on it: gravity (straight down), the ramp pushing back on the block (perpendicular to the slope, called the normal force $N$), and friction (along the slope) [1]; [2].

Trick: tilt your axes with the slope. Then gravity splits into "pulling the block down the slope" ($mg\sin\theta$) and "pressing it against the slope" ($mg\cos\theta$). The ramp pushes back exactly the second one, so $N = mg\cos\theta$ [1].

No friction? Only $mg\sin\theta$ is left along the slope, so [1]

$$a = g\sin\theta.$$

Steeper slope → bigger acceleration. Vertical slope → free fall.

With friction? When the block slides, friction pushes it back up the slope with size $\mu_k N$. The coefficient $\mu_k$ is a number between 0 (ice) and about 1 (rubber on dry road). Then [1]; [2]

$$a = g(\sin\theta - \mu_k\cos\theta).$$

Will it slide at all? If the block isn't moving yet, "static friction" quietly adjusts itself to hold the block, up to a maximum $\mu_s N$. Tilt the ramp more and more. The block starts to slip at the critical angle [1]:

$$\theta_c = \arctan(\mu_s).$$

Strings and pulleys. A light string under tension pulls each thing it ties to the same amount. Over a smooth pulley the tension $T$ is the same on both sides [2]. For a two-block system where one hangs and pulls the other through a pulley, you write $F = ma$ for each block and add them — the tension cancels, and you get the acceleration directly [1].

Theory

Forces on an inclined plane

A block of mass $m$ sits on a plane tilted at angle $\theta$ above the horizontal. Three forces may act on it: its weight $m\mathbf g$ (straight down), the normal force $\mathbf N$ (perpendicular to the surface), and friction (along the surface) [1, Worked Example “Motion on an Inclined Plane and Friction Forces”]; [2, §8.3].

Choose axes along ($x$) and perpendicular to ($y$) the surface. The weight splits into components [1]:

$$\begin{gathered}W_x = mg\sin\theta \ \ (\text{down the slope}), \\ W_y = -mg\cos\theta.\end{gathered}$$

Perpendicular to the slope the block does not accelerate, so $N = mg\cos\theta$ [1].

Frictionless slide

Without friction the only force along the slope is $mg\sin\theta$. Newton's second law gives [1]

$$a_x = \frac{F_{\text{net},x}}{m} = g\sin\theta.$$

Starting from rest at the top, $v(t) = g\sin\theta\,t$ and $x(t) = \tfrac12g\sin\theta\,t^2$. The acceleration is $g$ when the slope is vertical ($\theta = 90^\circ$) and $0$ when flat ($\theta = 0$) [1].

Kinetic friction

If the block slides and the surface is rough, a kinetic friction force acts opposite to the motion. Experimentally its magnitude is [1]; [2, §8.3.2]

$$f_k = \mu_k N,$$

where $\mu_k$ is the coefficient of kinetic friction, a dimensionless property of the two surfaces. Important: $f_k$ is independent of the contact area and (for ordinary speeds) of the sliding speed [2, §8.3.2].

Down the slope the net force is $mg\sin\theta - \mu_k mg\cos\theta$, so [1]

$$a_x = g(\sin\theta - \mu_k\cos\theta).$$

Static friction and the critical angle

When the block does not slide, friction is static. It takes whatever value (up to a limit) is needed to keep the block in equilibrium along the surface [1]; [2, §8.3.2]:

$$f_s \le f_{s,\max} = \mu_s N, \qquad \mu_s \gtrsim \mu_k.$$

Increase the tilt. The block is on the verge of slipping when $mg\sin\theta_c = \mu_s mg\cos\theta_c$, so [1]

$$\boxed{\theta_c = \arctan(\mu_s).}$$

Below $\theta_c$ it stays put; above $\theta_c$ it slides, with acceleration $g(\sin\theta - \mu_k\cos\theta)$.

Tension

A string (or rope) under tension pulls each body it connects along its length, toward the opposite end [2, §8.5]. For a massless, inextensible string over a smooth pulley, the tension $T$ is the same everywhere, and the pull on one body matches the pull on the other [2, §8.5.1].

Mass-pulley system (one block on a surface, one hanging): if the heavier block hangs and the lighter one lies on a surface with friction coefficient $\mu_k$ [1, Worked Example “Mass-Pulley System”]:

$$m_1a = T - \mu_k m_1g, \qquad m_2a = m_2g - T.$$

Adding eliminates $T$: $a = \dfrac{(m_2 - \mu_k m_1)\,g}{m_1 + m_2}$.

Note

Pick axes along the direction of motion. On the incline the perpendicular direction is a bookkeeping check ($N = mg\cos\theta$); only the parallel direction holds the equation of motion [1].

Warning

Static friction is not a fixed number. It equals whatever balances the applied force up to a maximum $\mu_s N$. Only kinetic friction has the fixed magnitude $f_k = \mu_k N$ [1]; [2, §8.3.2].

Visualization

The arrows show the three forces: gravity $mg$ (down), the normal force $N$ (perpendicular to the slope, up and out), and friction (dashed, along the slope opposite to the motion). The block's acceleration along the slope is $a = g(\sin\theta - \mu_k\cos\theta)$ (shown live). Try $\theta < \arctan(\mu_k)$: the kinetic prediction $a$ is non-positive and the block doesn't slide.

Key formulas

Worked examples

Example

A block is released from rest at the top of a frictionless incline of angle $\theta$. Find the acceleration and the velocity after it has slid a distance $d$. (From [1], Worked Example “Motion on an Inclined Plane and Friction Forces”, part (a).)

  1. Along the slope: $F_{\text{net}} = mg\sin\theta$, so $a = g\sin\theta$.

  2. From rest: $x(t) = \tfrac12 g\sin\theta\,t^2$ and $v(t) = g\sin\theta\,t$.

  3. Eliminate $t$: $v = \sqrt{2(g\sin\theta)\,d} = \sqrt{2gd\sin\theta}$.

Check

If the drop height is $h = d\sin\theta$, this is $v = \sqrt{2gh}$ — the same as free fall from height $h$. ✓

Example

Repeat with kinetic friction $\mu_k$. For what range of $\theta$ does the block actually accelerate? (From [1], part (b).)

  1. Normal force: $N = mg\cos\theta$, so the friction force is $f_k = \mu_k mg\cos\theta$, up the slope.

  2. Net force along slope: $mg\sin\theta - \mu_k mg\cos\theta$, so $a = g(\sin\theta - \mu_k\cos\theta)$.

  3. $a > 0$ requires $\tan\theta > \mu_k$. If $\tan\theta \le \mu_k$ the kinetic model predicts the block decelerates or stays at rest.

Check

Setting $\mu_k = 0$ gives $a = g\sin\theta$ ✓. Setting $\theta = 90^\circ$: friction vanishes ($\cos90^\circ = 0$), so $a = g$ ✓.

Example

Find the critical angle at which a block just begins to slide on a surface with static-friction coefficient $\mu_s$. (From [1], part (c).)

  1. Just before sliding, static friction is maximum: $f_{s,\max} = \mu_s N = \mu_s mg\cos\theta_c$.

  2. Along the slope the forces balance: $mg\sin\theta_c = \mu_s mg\cos\theta_c$.

  3. Divide: $\tan\theta_c = \mu_s$, so $\theta_c = \arctan(\mu_s)$.

Check

$\mu_s = 0$: $\theta_c = 0$ — any tilt lets a frictionless block slide ✓. $\mu_s = 1$: $\theta_c = 45^\circ$ ✓.

Example

Mass $m_2$ hangs from a string over a smooth pulley; $m_1$ sits on a horizontal surface with kinetic friction $\mu_k$. The system is released. Find the acceleration and the tension. (Adapted from [1], Worked Example “Mass-Pulley System”, using [2, §8.5].)

  1. For $m_1$: along the surface, $m_1a = T - \mu_k m_1g$.

  2. For $m_2$: vertically, $m_2a = m_2g - T$.

  3. Add: $(m_1 + m_2)\,a = (m_2 - \mu_k m_1)\,g$, so $a = \dfrac{(m_2 - \mu_k m_1)\,g}{m_1 + m_2}$.

  4. Substitute back: $T = m_2(g - a) = \dfrac{m_1m_2(1 + \mu_k)\,g}{m_1 + m_2}$.

Check

$\mu_k = 0$: the Atwood answer $a = m_2g/(m_1+m_2)$, $T = m_1m_2g/(m_1+m_2)$ ✓. The system accelerates only if $m_2 > \mu_k m_1$ ✓.
