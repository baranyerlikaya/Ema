1st and 2nd Order Homogeneous ODEs

Solving linear homogeneous ODEs: ẋ + p(t)x = 0 by integrating, and ẍ + bẋ + cx = 0 by the ansatz e^{λt} and the characteristic equation. The key to oscillators.

In short

A differential equation is a riddle. "Find a function whose derivatives fit this rule." The order is the highest derivative in the rule. The answer always has some free numbers in it: one for first order, two for second order. You choose them from how things start, such as where something was and how fast it was moving [1]; [2].

First order: $\dot x = \lambda x$. "Things change in proportion to how much there is", like money earning interest. The answer is $x = x(0)\,e^{\lambda t}$: growth if $\lambda > 0$, decay if $\lambda < 0$ [2].

Second order: $\ddot x + b\dot x + cx = 0$. The trick is to guess $x = e^{\lambda t}$. Each derivative just multiplies by $\lambda$, so the riddle turns into an ordinary quadratic equation, the characteristic equation [1]; [2]:

$$\lambda^2 + b\lambda + c = 0.$$

Its two answers decide the motion [1]; [2]:

  • two different real roots: two exponentials, $x = Ae^{\lambda_1 t} + Be^{\lambda_2 t}$, no wiggling;
  • complex roots $\alpha \pm i\omega$: a wiggle with a growing or shrinking size, $x = e^{\alpha t}(C\cos\omega t + D\sin\omega t)$;
  • one repeated root: $x = (A + Bt)\,e^{\lambda t}$.

The spring. A mass on a spring follows $\ddot x + \omega_0^2 x = 0$ with $\omega_0 = \sqrt{k/m}$. It swings forever: $x = R\cos(\omega_0 t + \phi)$. Stiffer spring or lighter mass means faster swinging. How big the swing is ($R$) and where it starts ($\phi$) come from the start; $\omega_0$ doesn't [1].

Add friction ($\ddot x + 2\gamma\dot x + \omega_0^2 x = 0$, $\gamma = b/2m$). A little friction ($\gamma < \omega_0$): it swings, but the swings get smaller. Just enough ($\gamma = \omega_0$, critical): it slides back to the middle without swinging, sooner than with more friction. Too much ($\gamma > \omega_0$): it creeps back slowly, still without swinging [1].

Remember: second order needs two starting facts, the start position and the start velocity [1].

Theory

The language

An ordinary differential equation (ODE) is a relation between an unknown function $x(t)$ and its derivatives; a solution is a function that satisfies it [2, §1.3]. Its order is the highest derivative that appears. It is linear if $x$ and its derivatives appear only to the first power, multiplied by coefficients that depend on $t$ alone, and homogeneous if there is no term without $x$ (the right-hand side is zero) [2, §3.1].

The general solution contains free constants: one for a first-order equation, two for a second-order equation. They are fixed by initial conditions, for example $x(0)$ and $\dot x(0)$ in mechanics [1, §Solution to the Equation of Motion]; [2, §1.4, §3.1].

Linear homogeneous equations have a key property, superposition: if $x_1$ and $x_2$ are solutions, then so is any combination $c_1x_1 + c_2x_2$ [2, §3.1]; [1].

First order: ẋ + p(t)x = 0

A first-order linear homogeneous equation can be separated and integrated. The general solution is [2, §3.1]

$$x(t) = c\,e^{-\int_a^t p(\tau)\,d\tau}, \qquad c = x(a).$$

If $p$ is a constant, this is simply $x = c\,e^{-pt}$. Equivalently, $\dot x = \lambda x$ has the solution $x = x(0)\,e^{\lambda t}$: growth for $\lambda > 0$, decay for $\lambda < 0$ [2, §3.1, §6.1].

Because an exponential is never zero, a solution is either zero everywhere or never zero [2, §3.1].

Second order with constant coefficients

Consider $\ddot x + b\,\dot x + c\,x = 0$ with constant $b$ and $c$. Try $x = e^{\lambda t}$. Each derivative brings down a factor $\lambda$, so the equation becomes $(\lambda^2 + b\lambda + c)\,e^{\lambda t} = 0$. The exponential is never zero, so $\lambda$ must solve the characteristic equation [1, §Solution to the Equation of Motion]; [2, §6.1]:

$$\lambda^2 + b\lambda + c = 0, \qquad \lambda_{1,2} = \frac{-b \pm \sqrt{b^2 - 4c}}{2}.$$

Each root gives a solution $e^{\lambda t}$, and by superposition the general solution is a combination of two independent ones. What it looks like depends on the roots.

The three cases

Two distinct real roots ($b^2 > 4c$): $x = A\,e^{\lambda_1 t} + B\,e^{\lambda_2 t}$ [2, §6.1]; [1, §Overdamped Motion].

Complex pair $\lambda = \alpha \pm i\omega$ ($b^2 < 4c$): the complex solutions $e^{(\alpha\pm i\omega)t}$ combine into two real ones, the real and imaginary parts of $e^{(\alpha+i\omega)t}$ [2, §6.2]:

$$\begin{aligned}x &= e^{\alpha t}\left(C\cos\omega t + D\sin\omega t\right) \\ &= R\,e^{\alpha t}\cos(\omega t + \phi).\end{aligned}$$

Repeated root $\lambda_1 = \lambda_2 = \lambda$ ($b^2 = 4c$): $e^{\lambda t}$ is only one solution. The second is $t\,e^{\lambda t}$, so $x = (A + Bt)\,e^{\lambda t}$ [1, §Critically Damped Oscillations].

The oscillator equations

Newton's second law for a mass on a spring, $m\ddot x = -kx$, gives the simple harmonic oscillator [1, §Equation of Motion for Simple Oscillations]:

$$\ddot x + \omega_0^2 x = 0, \qquad \omega_0 = \sqrt{k/m}.$$

The roots are $\lambda = \pm i\omega_0$, so $x = C\cos\omega_0 t + D\sin\omega_0 t = R\cos(\omega_0 t + \phi)$, with period $T = 2\pi/\omega_0$ [1].

Adding a drag force $-b\dot x$ gives the damped oscillator $\ddot x + 2\gamma\dot x + \omega_0^2 x = 0$ with $\gamma = b/2m$. Its roots $\lambda = -\gamma \pm \sqrt{\gamma^2 - \omega_0^2}$ produce exactly the three cases above [1, §Damped Oscillations]:

  • underdamped ($\gamma < \omega_0$): $x = R\,e^{-\gamma t}\cos(\omega_1 t + \phi)$ with $\omega_1 = \sqrt{\omega_0^2 - \gamma^2}$;
  • critically damped ($\gamma = \omega_0$): $x = (A + Bt)\,e^{-\gamma t}$;
  • overdamped ($\gamma > \omega_0$): $x = A\,e^{\lambda_1 t} + B\,e^{\lambda_2 t}$ with both $\lambda$ negative.

Note

The angular frequency $\omega_0$ depends only on the system ($k$ and $m$), not on the initial conditions. The amplitude $R$ and phase $\phi$ are the two free constants, and they are set by $x(0)$ and $\dot x(0)$ [1, §Physical Interpretation of the General Solution].

Warning

A second-order equation needs two initial conditions. Fixing only $x(0)$ leaves a whole family of possible motions. Use both the initial position and the initial velocity to find both constants [1, §Solution to the Equation of Motion].

Visualization

A mass $m$ on a spring of stiffness $k$, with friction $b$, released from $x = 1$ at rest. The graph shows $x(t)$, which solves $\ddot x + 2\gamma\dot x + \omega_0^2 x = 0$ with $\gamma = b/2m$ and $\omega_0 = \sqrt{k/m}$ (shown at the top right). $b = 0$: undamped, steady oscillation. Small $b$: underdamped, the swings shrink. Try $k = 2\ \text{N/m}$ and $m = 0.2\ \text{kg}$: then critical damping $\gamma = \omega_0$ is at $b = 2\sqrt{km} \approx 1.26\ \text{kg/s}$. Above that the motion is overdamped and the mass creeps back without oscillating.

Key formulas

Worked examples

Example

Solve $\ddot x + \omega_0^2 x = 0$ with $x(0) = x_0$ and $\dot x(0) = v_0$, and write the answer in amplitude–phase form. (From [1], §Solution to the Equation of Motion and §Amplitude-Phase Form.)

  1. Characteristic equation $\lambda^2 + \omega_0^2 = 0$, so $\lambda = \pm i\omega_0$. The real general solution is $x = C\cos\omega_0 t + D\sin\omega_0 t$.

  2. At $t = 0$: $x(0) = C = x_0$. Differentiate, $\dot x = -C\omega_0\sin\omega_0 t + D\omega_0\cos\omega_0 t$, so $\dot x(0) = D\omega_0 = v_0$ and $D = v_0/\omega_0$:

    $$x(t) = x_0\cos\omega_0 t + \frac{v_0}{\omega_0}\sin\omega_0 t.$$

  3. Write it as $x = R\cos(\omega_0 t + \phi)$ with

    $$R = \sqrt{x_0^2 + \frac{v_0^2}{\omega_0^2}}, \qquad \tan\phi = -\frac{v_0}{\omega_0 x_0}.$$

Check

$R\cos(\omega_0 t + \phi) = R\cos\phi\cos\omega_0 t - R\sin\phi\sin\omega_0 t$. Matching gives $R\cos\phi = x_0$ and $R\sin\phi = -v_0/\omega_0$, which reproduce both formulas. ✓

Example

Solve the critically damped equation $\ddot x + 2\gamma\dot x + \gamma^2 x = 0$ with $x(0) = x_0$, $\dot x(0) = v_0$. (From [1], §Critically Damped Oscillations.)

  1. The characteristic equation $\lambda^2 + 2\gamma\lambda + \gamma^2 = (\lambda + \gamma)^2 = 0$ has the double root $\lambda = -\gamma$, giving only one solution $e^{-\gamma t}$.

  2. Multiply the equation by $e^{\gamma t}$. By the product rule, the left side is exactly $\frac{d^2}{dt^2}\left[e^{\gamma t}x\right]$, so

    $$\frac{d^2}{dt^2}\left[e^{\gamma t}x\right] = 0 \;\Rightarrow\; e^{\gamma t}x = A + Bt.$$

  3. So $x = (A + Bt)\,e^{-\gamma t}$. From $x(0) = A = x_0$ and $\dot x(0) = B - \gamma A = v_0$:

    $$x(t) = \left[x_0 + (v_0 + \gamma x_0)\,t\right]e^{-\gamma t}.$$

Check

At $t = 0$ this gives $x_0$ ✓. As $t \to \infty$, $t\,e^{-\gamma t} \to 0$, so the particle returns to equilibrium without oscillating, as [1] states.

Example

Find the real general solution of $\ddot x + 2\dot x + 2x = 0$. (From [2], §6.1–6.2.)

  1. Characteristic equation: $\lambda^2 + 2\lambda + 2 = 0$, so $\lambda = \frac{-2 \pm \sqrt{4 - 8}}{2} = -1 \pm i$.

  2. Complex pair with $\alpha = -1$, $\omega = 1$. The real and imaginary parts of $e^{(-1+i)t} = e^{-t}(\cos t + i\sin t)$ are both solutions:

    $$x(t) = e^{-t}\left(C\cos t + D\sin t\right).$$

Check

Take $x = e^{-t}\cos t$: $\dot x = -e^{-t}(\cos t + \sin t)$ and $\ddot x = 2e^{-t}\sin t$. Then $\ddot x + 2\dot x + 2x = e^{-t}(2\sin t - 2\cos t - 2\sin t + 2\cos t) = 0$. ✓

Example

Money in a savings account earns interest continuously at rate $I$ per year, with no deposits or withdrawals. Write and solve the equation for the balance $x(t)$. (From [2], §2.1 and §3.1.)

  1. Over a short time $\Delta t$ the bank adds $I\,x\,\Delta t$, so $\dfrac{x(t+\Delta t) - x(t)}{\Delta t} = Ix$. In the limit $\Delta t \to 0$: $\dot x = Ix$.

  2. This is first-order, linear and homogeneous with $p = -I$ constant. So $x(t) = x(0)\,e^{It}$.

Check

$\dot x = I\,x(0)\,e^{It} = Ix$ ✓, and $x(0)$ is reproduced at $t = 0$. The same equation with $\lambda < 0$ in place of $I$ describes exponential decay.
